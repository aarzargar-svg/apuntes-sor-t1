## ⌨️ Comandos y pasos importantes

`pwd` Muestra la ruta de la carpeta actual.

`ls` Muestra los archivos y carpetas.

`cd ..` Vuelve a la carpeta anterior.

`git clone` Descarga y clona un repositorio.

`git status` Muestra el estado de los cambios.

`git remote -v` Muestra la dirección del repositorio remoto.

`git add .` Prepara los archivos modificados para subirlos.

`git commit -m "mensaje"` Guarda los cambios con un mensaje.

`git push` Sube los cambios a GitHub.

`git log` Muestra el historial de cambios.

`git restore` Recupera archivos a su estado anterior.
